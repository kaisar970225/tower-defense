# 🏰 Tower Defense

A browser-based Tower Defense game built with vanilla JavaScript and Canvas API.

## 🎮 Demo

> Place towers on the green cells to stop enemies from reaching the end!

## 🕹️ How to Play

- Click on a **green cell** to place a tower
- Choose tower type from the **bottom panel**
- Enemies walk along the **yellow path**
- If an enemy reaches the end you lose a ❤️
- Earn 💰 by killing enemies and spend it on towers

## 🏰 Tower Types

| Tower | Cost | Damage | Range | Fire Rate |
|-------|------|--------|-------|-----------|
| 🟢 Basic | 25💰 | 20 | Medium | Medium |
| 🔵 Sniper | 50💰 | 60 | Long | Slow |
| 🔴 Rapid | 35💰 | 10 | Short | Fast |

## 🛠️ Built With

- Vanilla JavaScript (ES6+)
- Canvas API
- HTML5 / CSS3

## 🚀 Run Locally

1. Clone the repo
```bash
   git clone https://github.com/kaisar970225/tower-defense.git
```
2. Open in VS Code
3. Run with **Live Server** extension
4. Open `http://localhost:5500`
